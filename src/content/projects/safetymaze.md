## 01 Overview

SafetyMaze was a personal Python project created to explore how a laser beam could travel and reflect through a controlled maze environment.

The idea was to build a visual simulation where different maze layouts, beam starting positions, and beam angles could be tested. It was developed as an early concept for safety validation and design verification, rather than as a finished engineering tool.

The project also gave me a practical way to improve my Python skills while working with geometry, simulation logic, graphical interfaces, and visual feedback.

## 02 What I built

The completed proof of concept included:

- A system for simulating beam movement and reflections
- Multiple maze layouts and selectable presets
- Adjustable beam angles and starting conditions
- A graphical interface for controlling the simulation
- A visual representation of the calculated beam path
- A stage-based development structure that allowed new features to be added gradually

The beam simulation logic was kept separate from the graphical interface. This made the project easier to understand, troubleshoot, and expand during development.

The project was developed in stages rather than attempting to build the complete system at once. Early versions focused on displaying the maze and defining the beam starting position. Reflection logic, configuration options, and interface controls were then introduced gradually.

## 03 Project outcome

SafetyMaze reached a working proof-of-concept stage.

The completed version could display different maze configurations, simulate beam paths, and visualise how the beam reflected through the selected environment. It demonstrated the main idea successfully and provided a useful foundation for future simulation or engineering tools.

Development stopped after the project achieved its original proof-of-concept purpose. My focus shifted towards other projects and priorities, and developing it into a more complete engineering tool would have required considerably more time.

I may return to the project in the future as my coding and simulation experience develops further. For now, it remains a completed concept rather than an actively developed product.

## 04 What I learned

SafetyMaze helped me improve my understanding of:

- Geometry and basic ray behaviour
- Translating physical behaviour into software logic
- Structuring a Python project into separate interface and calculation components
- Creating graphical interfaces for technical tools
- Building features through smaller development stages
- Using visual feedback to identify problems in simulation logic
- Recognising when a proof of concept has achieved its intended purpose

The project also showed me that a useful technical tool does not need to begin as a complete or highly accurate system. A smaller simulation can first be used to explore an idea, understand the main challenges, and decide whether further development is worthwhile.
